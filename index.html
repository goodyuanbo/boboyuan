Pi节点 搭建指南

按照以下步骤轻松搭建您的Pi节点。本教程支持Windows、Mac和Linux系统。

1

准备环境要求

确保您的系统满足以下要求：

  • 操作系统：Windows 10/11, macOS 10.15+, Ubuntu 20.04+
  • 内存：至少4GB RAM（推荐8GB）
  • 存储：至少100GB可用空间
  • 网络：稳定的互联网连接，开放端口31400-31409
  • Docker：需要安装Docker环境

选择您的操作系统查看具体安装命令：

# Windows (PowerShell) Install-Module DockerMsftProvider -Force Install-Package Docker -ProviderName DockerMsftProvider -Force
2

使用云服务器穿透搭建

对于没有公网IP的用户，我们推荐使用云服务器进行穿透搭建：

# 1. 购买云服务器（推荐阿里云、腾讯云） # 2. 登录服务器并安装Docker curl -fsSL https://get.docker.com -o get-docker.sh sudo sh get-docker.sh # 3. 下载Pi节点Docker镜像 docker pull pineetwork/pi-node:latest # 4. 运行Pi节点容器 docker run -d --name pi-node \ -p 31400-31409:31400-31409 \ -v ~/pi-data:/data \ pineetwork/pi-node:latest

注意： 确保云服务器安全组开放端口31400-31409。

3

配置节点和端口转发

配置节点并设置端口转发确保节点可被网络访问：

# 查看节点运行状态 docker logs pi-node # 获取节点ID docker exec pi-node cat /data/node-id.txt # 配置路由器端口转发（家用网络需要） # 转发外部端口31400-31409到节点服务器的相同端口

提示： 可以使用 canyouseeme.org 检查端口是否开放。

4

验证节点运行状态

使用以下命令验证节点是否正常运行：

# 检查容器运行状态 docker ps # 查看节点日志 docker logs --tail 50 pi-node # 测试节点API curl http://localhost:31400/api/status # 预期输出应包含 "status": "syncing" 或 "status": "ready"

常见 问题解答

以下是Pi节点搭建过程中最常见的问题和解决方案。

Pi节点有什么硬件要求？

Pi节点对硬件要求不高，但建议满足以下配置以获得更好性能：

  • 最低配置： 双核CPU，4GB RAM，100GB SSD
  • 推荐配置： 四核CPU，8GB RAM，200GB+ SSD
  • 网络要求： 10Mbps+带宽，开放端口31400-31409
  • 系统要求： 需要安装Docker，系统保持24/7运行
没有公网IP可以搭建节点吗？

可以，我们推荐使用云服务器进行穿透搭建：

  1. 购买云服务器（如阿里云、腾讯云、AWS等）
  2. 在云服务器上安装Docker和Pi节点
  3. 配置云服务器安全组开放必要端口
  4. 使用云服务器的公网IP运行节点

这种方法无需家庭网络公网IP，且服务器稳定性更高。

节点同步需要多长时间？

节点同步时间取决于网络条件和区块链数据大小：

  • 初始同步： 通常需要12-48小时
  • 快速网络： 如果带宽足够，可能缩短到6-12小时
  • 影响因素： 网络速度、硬盘性能、节点数量
  • 保持同步： 同步完成后，节点会实时更新新区块

同步期间请确保节点24/7运行，不要中断。

运行节点有什么奖励？

Pi节点运营商可以获得以下奖励：

  • 挖矿加成： 节点运行者可获得额外的Pi挖矿速率
  • 交易费用： 未来可能获得处理交易的费用
  • 治理权： 参与网络治理决策
  • 早期贡献者奖励： 作为网络早期建设者获得奖励

具体奖励机制将在Pi Network主网上线后确定。
